# 🛒 VibeCart - Premium E-Commerce Platform

VibeCart is a full-stack E-Commerce web application built with **Django**. It features a modern shopping experience with secure user authentication, dynamic product management, and automated email services.

## ✨ Features

- **User Accounts**: Comprehensive registration, login/logout, and profile management logic (`accounts` app).
- **Product Store**: Dynamic category-wise product listings and detail pages (`store` app).
- **Shopping Cart**: Fully functional dynamic cart system (Add/Remove/Update items).
- **Secure Payments**: Integrated with **Stripe API** for secure checkout and payment processing.
- **Email Notifications**: Configured with **SendGrid API** for automated transaction and system emails.
- **Responsive UI**: Built with **Bootstrap 5** and custom CSS for a premium, mobile-first design.

## 🛠️ Tech Stack

- **Backend**: Python & Django
- **Frontend**: HTML5, CSS3, Bootstrap 5
- **Database Architecture**: Django Model Classes
- **APIs**: Stripe (Payments), SendGrid (Email)
